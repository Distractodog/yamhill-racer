## Method and limits

- Shapely 2 STRtree finds all point intersections: highway/highway and highway/waterway (rail if present). All highway classes are included; JSON marks classes supported by the road baker. Each crossing is a row; remaining bridge/tunnel/nonzero-layer ways get a tag-only row. Disabled bridge/tunnel values and numeric layer zero do not count as active tags.
- Input contains geometry but no node IDs. Shared vertices at the crossing substitute for shared OSM nodes; coincident distinct nodes cannot be distinguished. This is a geometry audit, not proven topology.
- Excluded 11439 connected point crossings; 0 road pairs have linear overlap (not isolated crossing points). Tagged overlapping ways are still included. Multi-crossing ways can occur in several rows; counts are candidates, not unique structures.
- Railway ways in export: 0. Zero rail rows means no rail source coverage, not no railway bridges.
- Culvert-only means the waterway is explicitly tunnel-tagged; untagged stream crossings remain creek candidates. Tag-only overpasses have unknown obstacles. Layer values are listed per way; absent layer is 0.
- Length is the inferred deck way length inside the map, not a measured physical span. Heading follows that way; layer/bridge/tunnel tags choose the probable upper road at road crossings.
- Tag-only waterway rows have no identified deck road. Their driver PNG is a locator view along the waterway; the director must identify a road before treating that image as deck evidence.
- Priority is a static risk estimate: road crossings without a shared vertex first (longest deck way first), then river crossings (Sheridan Bridge first), then remaining candidates. The first five are the requested likely clipping spots, **not visually confirmed worst defects**. No terrain-height or valley-profile measurements were made.
- Every state and verdict is pending. Director must inspect both screenshots and record one of “deck dips into the valley”, “roads clip through each other”, or “fine”, with a one-line verdict. No screenshot has been generated or reviewed by this worker.
